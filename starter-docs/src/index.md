Welcome to the documentation. This page is `src/index.md`.

Every markdown file in `src/` is a page. `title` and `nav_order` in its front matter put it in the navigation, and
`parent: <title of another page>` puts it under that page (up to three levels).

Run `ombryt serve` and edit away; the browser reloads on every save.

# Instructions for coding agents

Read [CONTRIBUTING.md](CONTRIBUTING.md) first; it applies to agents as to everyone.

- Run the checks before you say a change is done, and report them as they came out.
- Check a fact in the code before you write it in the documentation.
- A change to templates, themes or output: build `docs/` and look at the result, not only the tests.
- Do not add dependencies without asking.
